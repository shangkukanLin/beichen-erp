# ADR-0004: 退货入库品质策略

- **状态**: 已采纳
- **日期**: 2026-07-31

## 背景

客户退货产品等级可能不准确——客户声称 C 规但实际可能是 B 规或不良。需要确定退货入库时的等级处理流程。

## 决策

退货入库按**客户声称等级直接入库**，后续质检如发现等级不符，通过**品质重分类单**纠错。

流程：
1. 退货入库 → 明细选择客户声称的品质等级 → 审核后按该等级入库
2. 内部质检 → 发现等级不符
3. 创建品质重分类单 → from_quality(错误等级) → to_quality(正确等级) → 审核

## 后果

- 无需"待入库"中间状态，流程简洁，不阻塞库存可用性
- 与采购入库流程对称：供应商声称等级 → 入库 → 质检 → 重分类
- 重分类单提供完整审计追踪（谁、何时、从什么等级调整到什么等级）
- 当前采购退货已支持品质选择，无需额外改动
