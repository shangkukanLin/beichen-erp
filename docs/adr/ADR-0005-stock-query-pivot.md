# ADR-0005: 库存查询后端 PIVOT 聚合

- **状态**: 已采纳
- **日期**: 2026-07-31

## 背景

品质等级引入后，库存查询页需要一行展示同一产品的各等级库存（A规/B规/C规/不良），而非平铺多行。例如：

| 产品 | 仓库 | A规 | B规 | C规 | 不良 |
|------|------|-----|-----|-----|------|
| FIND X7 屏幕 | 成品仓 | 50 | 20 | 5 | 0 |

## 决策

后端 `InventoryStockController` 负责 SQL GROUP BY (warehouse_id, product_id) + 应用层 PIVOT quality_type 聚合。前端直接渲染聚合结果，无需额外处理。

## 后果

- 分页逻辑正确：先聚合再分页，不会出现同一产品跨页的情况
- 性能可控：产品数量在数百级别时，GROUP BY + PIVOT 开销可接受
- 替换当前平铺列表视图，不再保留"详细模式"
- 需改造 `InventoryStockController.page()` 方法返回结构
