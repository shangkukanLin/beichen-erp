## 【长期规则】所有列表必须一行显示完、不左右滑动（用户要求，2026-09-24）

**规则**：全站任何表格（列表页 / 明细表 / 分析表）在目标窗口下都必须**一行显示完整**：不出现横向滚动条，
也不能有列被裁掉看不见。

**落地判据（可机器校验）**
1. Element Plus 的 `el-table` 是 `table-layout: fixed` + `width: 100%` ⇒ **列宽之和大于容器时不会横向滚动，
   而是把右侧列静默裁掉** ⇒ **只看有没有滚动条会把问题全部漏掉**（本次首轮扫描 6 页全是"被裁"、无一是滚动）。
   故两条都要量：`overflow = bodyWrapper.scrollWidth − clientWidth`、`clip = 末列右边缘 − 表格右边缘`。
2. 因此必须同时满足：
   - ① **列宽（`width` + `min-width`）合计 ≤ 内容区可用宽度**；
   - ② **至少一列用 `min-width`**（Element 只有存在 min-width 列时才会把容器余量分给它 ⇒ 宽屏才撑满、否则右侧留白）。
3. 可用宽度基准：**1200px 窗口**（项目既有口径）⇒ 内容区约 **950px**；表格带 `max-height` 时**再减 ~8px**
   （纵向滚动条占宽，实测 `/outsource/material-stock-log` 就差这 8px）。
4. 宽表可用 `size="small"`：单元格内边距 12px→8px，**每列省约 8px**（13 列的 `/analysis/tax` 靠它才装下）。
5. **表头文案不要与分组表头重复**（如分组已写「退回/换入」，叶子列就别再写「退回品质」）——
   重复前缀既浪费宽度又会被截断成「退回…」。

**校验脚本**：`tools/regression/scan-table-overflow.ps1`
（遍历 63 个菜单页，逐表同时量溢出与裁切；`-Only <regex>` 可分批跑，全量约 3 分钟）
