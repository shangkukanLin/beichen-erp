# 2026-09-25 工作日志（UI：委外加工列表「显示完整 + 可点进详情」）

## 【长期规则补充】「一行显示完」≠「显示完整」：新增截断判据

2026-09-24 的 `scan-table-overflow.ps1` 只证明**不横向滚动**（colSum ≤ avail）。
但 Element Plus 的文本单元格**天生省略号截断** ⇒ 表格可以「完美放得下」却每列都被切一半
（用户 2026-09-25 在「委外仓库详情 / 委外加工各列表」上看到的就是这种情况）。
⇒ 新增常驻守卫 **`tools/regression/scan-col-truncation.ps1`**（与 overflow 守卫并列，两个都要跑）。

**判据**：逐列统计 body 单元格 `cell.scrollWidth − cell.clientWidth > 1` 的数量（= 文本被切），
以及 `cell 高度 > 26px`（= 换行，破坏一行显示）。
- **FAIL**：非白名单列有截断，或任何单元格换行。
- **白名单**（允许省略号，因为长度无上界）：`ui-e2e-zh.json` → `col_allow_truncate`
  = 产品 / 物料 / 物料名称 / 退货·送修内容 / 出库源仓。
  ⚠️ 白名单比对必须在**浏览器内**做（PS 控制台按 GBK 解码子进程输出，回传的中文与 PS 变量永远匹配不上）。
- 范围：先把委外加工 6 页纳入（`$routes`），其他页整改后逐步加。

## 「产品 / 物料」列可点进详情（同一批的第二轮，用户口径「产品和物料也需要点击进入详细」）

**交互（新增共享组件 `beichen-erp-web/src/components/EntityLinks.vue`，8 个列位复用）**
- 单项 → 名称即链接；
- 多项 → 显示「首个 等 N 项」，点击弹 Popover，**逐项可点**；
- 无 id（历史数据/后端未给）→ 渲染默认插槽，回退原纯文本/tooltip（不改变现状）。
- ⚠️ **为什么不做「格内逐个链接」**：单元格 `overflow:hidden` + 省略号，被裁到可视区外的链接**点不到**
  ⇒ 多值必须用 Popover 才能保证每一项可达。

**跳转落点（都复用现成页面，未新建）**
- 产品 → `/product/detail/:id`（产品主数据详情，传 product.id）；
- 物料 → **`/outsource/material-stock/detail/:materialId`**（物料档案摘要 + 跨仓库存分布 + 点仓库看流水）。
  ⚠️ 委外物料**没有**主数据详情页（`/outsource/material-info` 只有列表 + 编辑弹框、无详情入口）——
  本批按用户确认复用库存分布详情，未新建页面；若日后要"物料主数据详情"需另做。

## 踩坑记录

- **编辑模板最容易撞车**：一次 `replace_in_file` 在「物料订单」表头处留下了重复的 `<el-table-column label="供应商">`，

  教训：改表格块后**先跑一遍守卫/打开页面看一眼**，别只看 lint（lint 对模板结构错误不敏感）。
- 后台跑守卫：`Start-Process powershell -ArgumentList ... -RedirectStandardOutput <log>` + 轮询日志，
  避免 CLI 空闲超时（守卫一次要 ~40s）。
